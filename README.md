Мобильное приложение для осознанных сновидений: личный дневник снов и справочник «Сонариум».

Разработано NISARIUM.

## 📱 Особенности
- **Дневник сновидений** — ведение записей о снах прямо на устройстве.
- **Справочник «Сонариум»** — подборка интересных фактов, теории и методов улучшения качества сна.
- **Локальное хранение** — конфиденциальность данных без отправки на сторонние серверы.
